# Tech Context & Runtime Environment

## 🛠️ Tech Stack & Dependencies
- **Framework**: Next.js 15 (App Router), React 19, TypeScript
- **Styling & UI**: Tailwind CSS, Lucide React Icons, Framer Motion
- **Database & ORM**: Prisma ORM, SQLite / PostgreSQL
- **AI Models & Engines**: Google Gemini 3.7 Flash, Gemini Vision, FLUX.1 Pro, AI Horde
- **3D Graphics**: Three.js, React Three Fiber (Tarot Reader)

## 🌐 Môi trường Runtime & API
- **Dev Server**: Runs on `http://localhost:3000` via `npm run dev`
- **Git Sync Command**: Executed via `npm run push` (`scripts/auto_git_sync.bat`)
- **Environment Variables**: Defined in `.env` (Chứa API keys, Database URL)
